## 📖 درباره‌ی پروژه

**مشاوره همراه** یک اپلیکیشن وب پیشرونده (PWA) است که تجربه‌ای بومی و لوکس را برای کاربران فراهم می‌کند. این اپ به‌عنوان یک لانچر حرفه‌ای طراحی شده و محتوای اصلی را از سایت `rosha-24.ir` دریافت می‌کند.

### ویژگی‌ها

- ✨ **طراحی لوکس** — پالت سرمه‌ای و طلایی
- ⚡ **سرعت بالا** — بارگذاری فوری، بدون تأخیر
- 📴 **پشتیبانی آفلاین** — Service Worker هوشمند
- 🔔 **نصب یک‌کلیکی** — PWA در سطح اپ‌های بومی
- 🌐 **بدون آدرس‌بار** — تجربه‌ی تمام‌صفحه
- 🌙 **حالت تاریک** — بهینه‌شده برای چشم
- 📱 **واکنش‌گرا** — از موبایل تا دسکتاپ
- ♿ **دسترس‌پذیر** — رعایت استانداردهای A11y
